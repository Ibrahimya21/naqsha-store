# نقشة

هذا مشروع واجهة متجر باسم **نقشة**.

المشروع حاليًا عبارة عن **Front-End فقط**، وفيه صفحات أساسية للعرض، البحث، السلة، الشحن، والدفع، مع صفحات تسجيل الدخول وإنشاء حساب.

## الموجود داخل المشروع

- الصفحة الرئيسية
- صفحة البحث
- صفحة السلة
- صفحة معلومات الشحن
- صفحة الدفع بالبطاقة
- صفحة إثبات الدفع بالتحويل
- صفحة تسجيل الدخول
- صفحة إنشاء حساب

## ملاحظات سريعة

- المشروع ثابت حاليًا، يعني لا يوجد Backend حقيقي.
- بعض النماذج تعمل بشكل تجريبي فقط.
- السلة والشحن وبعض البيانات تنحفظ محليًا باستخدام `localStorage`.
- التنسيقات موجودة داخل `assets/css`.
- التفاعل البرمجي موجود داخل `assets/js/site.js`.

## تقسيم الملفات

- `pages/` صفحات الموقع
- `assets/css/` ملفات التنسيق
- `assets/js/` الجافاسكربت
- `assets/images/` الصور والمعاينات
- `components/` أجزاء مشتركة مثل الهيدر والفوتر
